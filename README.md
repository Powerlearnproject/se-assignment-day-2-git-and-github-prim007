Common Challenges and Pitfalls for New GitHub Users
1. New users often struggle with the fundamental Git concepts like staging, committing, branching, and merging.
2.Merge conflicts can be intimidating, especially when multiple people are working on the same files.

3.Forgetting to git pull before git push can lead to overwritten changes or conflicts.
4.Vague or inconsistent commit messages make it difficult to understand the project's history.
5.Committing unnecessary files (like temporary files or build artifacts) clutters the repository and wastes space.
6.Creating too many branches or failing to delete old branches can make the repository messy.
7.Bypassing pull requests can lead to poorly reviewed code being merged into the main branch.
